## Books I've Read

### Zero to One — Peter Thiel
**Key Takeaways:**
- Go from 0→1 (create new), not 1→n (copy existing)
- Build monopolies, not competitive businesses
- Find secrets — truths most people don't see
- Start small, dominate, then expand

**Best Quote:**  
> "What important truth do very few people agree with you on?"

**Content I Can Make From This:**
- [ ] "The one question that changed how I think about ideas"
- [ ] "Why competing is for losers (and what to do instead)"

---

### The Lean Startup — Eric Ries
**Key Takeaways:**
- Build → Measure → Learn (repeat fast)
- MVP: build the smallest thing that lets you learn
- Validated learning > building features
- Pivot or persevere based on real data

**Content I Can Make From This:**
- [ ] "Don't build for 6 months. Build for 6 days."
- [ ] "How I test ideas before wasting time"
