# 🎬 Reel Script Templates

> Don't write a script. Use a STRUCTURE. Fill in the blanks. Hit record.

---

## Template 1: The Realization (30-60 sec)
```
HOOK: "I used to think [common belief]..."
TURN: "Then [specific thing happened]..."
LESSON: "Now I think [new belief]."
CTA: "What's something YOU used to believe that turned out to be wrong?"
```

## Template 2: The Fear Post (30-45 sec)
```
HOOK: "Today I did something that terrified me."
WHAT: "I [specific action]."
RESULT: "Here's what actually happened: [honest truth]."
FEELING: "I feel [emotion] and I'm posting this anyway."
```

## Template 3: The Rant (30-60 sec)
```
HOOK: "Nobody talks about this but..."
POINT: "[Your honest opinion on something]"
EVIDENCE: "I know this because [personal experience]"
CLOSE: "Am I wrong? Tell me."
```

## Template 4: The Teach (45-60 sec)
```
HOOK: "Here's something I learned this week that I can't stop thinking about."
CONCEPT: "[Explain the idea simply]"
EXAMPLE: "[How it showed up in your life]"
TAKEAWAY: "[One line summary]"
```

## Template 5: The Raw Moment (15-30 sec)
```
[No structure. Just you, right after something happened.
Film your face. Say what you feel. Post it.]
```

## Template 6: The Challenge (30-45 sec)
```
HOOK: "I challenged myself to [thing] today."
BEFORE: "[How I felt before doing it]"
DURING: "[What it was actually like]"
AFTER: "[How I feel now]"
```

---

## Rules
1. First 3 seconds = HOOK. If you don't grab them, they scroll.
2. Look at the camera. Not at yourself on screen.
3. Speak like you're talking to ONE friend, not an audience.
4. Imperfect > polished. Always.
5. Under 60 seconds until you have 5K+ followers.
