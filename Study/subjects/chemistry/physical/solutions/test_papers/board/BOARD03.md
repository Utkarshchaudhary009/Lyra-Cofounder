**Section C:**
**Q19:** Binary: 2 components (NaCl + H₂O). Ternary: 3 components (NaCl + KCl + H₂O). Quaternary: 4 components (NaCl + KCl + CaCl₂ + H₂O).

**Q20:** Assume 1 L solution: n = 0.2 mol, mass_H₂SO₄ = 0.2×98 = 19.6 g.
Mass_solution = 1000×1.02 = 1020 g. Mass_solvent = 1020−19.6 = 1000.4 g = 1.0004 kg.
m = 0.2/1.0004 ≈ 0.2 m.

**Q21:** n_urea = 2/60 = 0.0333; n_water = 100/18 = 5.556. χ_urea = 0.0333/5.589 = 0.00596.

**Q24:** For an electrolyte dissociating into n ions: initial moles = 1, after dissociation: 1−α + nα = 1 + (n−1)α. i = [1+(n−1)α]/1 = 1 + (n−1)α.

**Q25:** ΔT_f = 5.50−5.449 = 0.051°C. Expected ΔT_f = 5.12×0.02 = 0.1024°C. i = 0.051/0.1024 = 0.498 ≈ 0.5.
β = 2(1−0.5) = 1.0 = 100% dimerization.

**Q26:** ΔT_b ∝ i. i values: Glucose=1, NaCl=2, CaCl₂=3, AlCl₃=4.
BP order: Glucose < NaCl < CaCl₂ < AlCl₃ (increasing).
